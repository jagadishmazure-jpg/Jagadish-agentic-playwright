# Fixtures (synthetic)

Larkspur Outfitters and all its products are fictional. We wrote the descriptions ourselves. 29 follow every rule, and 21 break 1 to 3 rules on purpose. No model generated them.

| File | What it does |
|---|---|
| `catalog.json` | 10 products: SKU, name, materials, care note, approved claims |
| `descriptions.json` | 50 descriptions keyed by `case_id`, replayed by `provider.js` |
