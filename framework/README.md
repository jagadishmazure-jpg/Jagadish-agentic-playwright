# Framework

The reusable QA framework (role 1). Tests import only from here.

| File | What it does |
|---|---|
| `api/` | Typed API client |
| `config/` | Environment profiles |
| `fixtures/` | Custom `test` with page objects and clients, custom matchers |
| `healing/` | Offline locator healer |
| `pages/` | Page objects |
| `utils/` | Semantic judge, accessibility, test data, reusable actions |
